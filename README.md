fifer
=====

The `fifer` package is a collection of R functions for data manipulation, data analysis, and plotting.

To install the development version [hosted on GitHub](https://github.com/dustinfife/fifer), execute:
```r
install.packages("devtools")
devtools::install_github(repo="dustinfife/fifer")
```

To install the release version [hosted on CRAN](http://cran.r-project.org/web/packages/fifer/index.html), execute:
```r
install.packages("fifer")
```
